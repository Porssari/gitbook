# 2. Lisää Home Assistant manuaalisena laitteena

Täytä manuaalisen laitteen lomake:

* Anna laitteelle nimi
* Valitse laitetyypiksi Home Assistant
* Valitse ohjauskanavamäärä
* Valitse **Luo ohjaukset laitteen kanaville automaattisesti.**
* Valitse rakennus, johon ohjaukset luodaan

Tallenna laite. Järjestelmä antaa laitteelle yksilöllisen laitetunnuksen muodossa `HA…`. Tätä tunnusta käytetään seuraavassa vaiheessa Home Assistantin asetuksissa.
