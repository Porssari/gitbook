# 3. Lisää YAML Home Assistantiin

Siirry [Pörssärin Home Assistant -asiakkaan](https://github.com/Porssari/HomeAssistant-client) ohjeeseen ja lisää YAML-konfiguraatio sen mukaan. Käytä Pörssärissä juuri luodulle laitteelle annettua laitetunnistetta asiakkaan asetuksissa. Älä tallenna tunnistetta julkiseen asetustiedostoon.
