# Shelly-ohjauksen lisääminen

Tämän oppaan avulla saat lisättyä Shelly-laitteesi Pörssäri-tilille.

Yhdistä ensin Shelly-rele kotiverkkoosi. Voit tehdä sen joko Shelly Smart Control -sovelluksella tai suoraan Shellyn luoman langattoman verkon kautta. Kun olet saanut laitteen lisättyä verkkoon, liity tietokoneella/mobiililaitteella samaan langattomaan verkkoon kuin mihin Shelly on yhdistetty.

Oppaan läpikäymiseksi sinulla tulee olla tiedossa Shellyn IP-osoite omassa kotiverkossa sekä Shellyn **12-merkkinen laitetunnus**.

{% hint style="info" %}
**Shelly-adoptointi (adoptiokoodi)** näkyy Lisää laite -valikossa, mutta ominaisuus on vielä tulossa. Käytä toistaiseksi manuaalista laitteen lisäystä.
{% endhint %}
