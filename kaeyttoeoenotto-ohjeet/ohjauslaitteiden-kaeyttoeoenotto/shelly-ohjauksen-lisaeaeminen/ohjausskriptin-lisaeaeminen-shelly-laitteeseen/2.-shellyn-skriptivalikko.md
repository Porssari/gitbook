# 2. Shellyn skriptivalikko

Selaimessa aukeaa tyhjä skriptivalikko. Siirry lisäämään Pörssärin ohjausskriptit valitsemalla oikeasta yläreunasta "Library".

{% hint style="info" %}
Jos laitteessa on ennestään Pörssärin skriptejä, käytä niiden korvaamiseen [päivitysohjetta](../../../../ohjauslaitteiden-ohjeet/ohjauslaitteiden-paeivitys/shelly-ohjausskriptin-paeivitys/README.md). Tämä ohje on tarkoitettu laitteelle, johon Pörssärin skriptejä ei ole vielä asennettu.
{% endhint %}
