# 1. Siirtyminen skriptivalikkoon

{% hint style="info" %}
Ohjausskriptin lisääminen ei toistaiseksi onnistu Smart Control -mobiilisovelluksella, mutta Shelly-releen IP-osoitteen löydät Smart Control -sovelluksen verkkoasetuksista, tyypillisesti kohdasta Wi-Fi 1. Osoite on yleensä muotoa 192.168.x.x.
{% endhint %}
Mene mobiililaitteen tai tietokoneen selaimella Shelly-laitteesi ohjausliittymään kirjoittamalla osoitteeksi Shelly-releen IP-osoite. Avaa laitteen asetusvalikko ja valitse **Scripts**.

{% hint style="info" %}
Älä käytä skriptin lisäämiseen Shellyn tukiaseman kautta osoitteessa 192.168.33.1 avattua käyttöliittymää. Skriptikirjaston avaaminen vaatii, että asetuksia käyttävällä laitteella on internet-yhteys.
{% endhint %}
