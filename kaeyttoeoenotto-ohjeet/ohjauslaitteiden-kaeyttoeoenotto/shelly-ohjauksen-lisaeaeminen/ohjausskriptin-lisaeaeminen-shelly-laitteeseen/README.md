# Ohjausskriptin lisääminen Shelly-laitteeseen

Tämän oppaan avulla lisäät ohjausskriptin Shelly-releeseen.

Shellyn adoptiokoodilla tehtävä käyttöönotto edellyttää Pörssäri-skriptiversiota, joka näyttää Shellyn käyttöliittymässä kentän **porssari_adoption_code**. Jos kenttää ei näy skriptin käynnistämisen jälkeen, päivitä skripti käyttöympäristöllesi julkaistuun adoptiokoodia tukevaan versioon.
