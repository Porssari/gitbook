# 4. Uuden ohjausskriptin lisääminen

Lisää ensin Pörssärin pääskripti valitsemalla kirjastosta **Insert Code**.

Tallenna skripti avautuvasta ikkunasta painamalla “Save”.

Palaa tämän jälkeen **Scripts**-valikkoon ja tee sama valvontaskriptille: **Insert Code → Save**. Lisää skriptit tässä järjestyksessä, jotta valvontaskripti voidaan kohdistaa oikein.

Kun valvontaskripti on tallennettu, palaa **Scripts**-valikkoon.
