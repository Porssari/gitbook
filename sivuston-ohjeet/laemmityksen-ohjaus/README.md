# 🌡 Lämmityksen ohjaus

Pörssäri ajoittaa rakennuksen lämmitystä sääennusteen, rakennuksen lämmitystarpeen ja sähkön hinnan perusteella. Käyttöönotto tehdään nykyisessä sovelluksessa seuraavassa järjestyksessä:

1. Lisää käyttöpaikka, rakennus ja lämmitystä ohjaava laite.
2. Tallenna rakennuksen lämmitysasetukset ja lisää vähintään yksi lämmitettävä tila.
3. Lisää lämmitysjärjestelmä ja valitse sen lämmittämät tilat.
4. Liitä lämmitysjärjestelmän ohjaukseen oikea laitekanava.

{% hint style="info" %}
**Lisää lämmitysjärjestelmä** -painike näkyy vasta, kun rakennukselle on tallennettu vuotuinen lämmitystarve, lämmitettävä pinta-ala ja vähintään yksi tila.
{% endhint %}
