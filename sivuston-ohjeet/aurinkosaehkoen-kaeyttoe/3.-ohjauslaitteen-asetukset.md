# 2. Aurinkosähkön hyödyntäminen

Kun käyttöpaikalle on lisätty aurinkovoimala onnistuneesti, avaa **Ohjaukset**, valitse haluamasi ohjaus ja ota aurinkoennusteen hyödyntäminen käyttöön ohjauksen asetuksissa. Tällöin laitteen ohjaukset muodostetaan vuorokauden aurinkoennuste huomioiden.

{% hint style="info" %}
Pörssäri valitsee ajankohdat aurinkosähköennusteen ja käyttäjän hinta-asetusten perusteella. Ohjausasetuksissa määritetty tuntimäärä toteutetaan joka vuorokausi riippumatta siitä, tuottaako oma aurinkovoimala sähköä.
{% endhint %}

Asetusten tallennuksen jälkeen ohjaus huomioi aurinkoennusteen ja pyrkii hyödyntämään omaa aurinkovoimalaa mahdollisimman tehokkaasti.
